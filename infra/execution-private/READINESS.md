# Activation ledger

Everything here remains source-only. No new production state, paid model call,
phone policy, merge or deployment is authorized by this file.

## Source path chosen

Use documented Agent37 authenticated exec to move bounded private mailbox data.
Do not require external Unix-socket injection, hostname allowlisting, a new
provider/account or changes to the retained working phone. Task-local sockets
and randomly authenticated loopback hold no upstream/account credential.
Controller owns execution binding, capability, durable dispatch claims,
quote/reservation/settlement, model routing and memory permissions.

## Proven locally

- Real T3 ACP conversation reaches actual Dock Next routes, canonical memory and
  current Graphify snapshot; responsive390px web conversation inspected.
- Real Pi tool turn reaches actual Next/Postgres over private model+memory
  sockets; one own private note and two settled model calls; no task bearer.
- Two concurrent network-isolated roots run the exact fresh-state candidate Pi
  wrapper using spool transport, each own two settlements and one private note.
- Fixed exec read/reply commands execute locally, bind envelope/file identity,
  refuse symlinks, keep shell input data-only and skip durable claimed IDs.
- Actual local Postgres concurrent claim race has one winner; unprivileged read
  denied. Independent worker continues after local workload death; endpoint
  outage emits failure output. Missing-heartbeat monitor has recovery tests.

## Not yet proven or activated

1. Candidate image has no new built/published digest. Old repaired disposable
   hosts do not attest this new source. Cloud build context must be a separately
   staged allowlist: Agent37 CLI docs say its packer ignores dockerignore
   negations. Do not upload a full working repository to that packer.
2. Remote exec mailbox permissions/latency, final nonroot policy and no routed
   application listener need qualification on a new explicitly approved host.
   The former two-host paid test is exhausted; retained phone is excluded.
3. Mailbox ledger and worker are not deployed. Need controller ownership,
   supervisor, independent missed-heartbeat destination and failure test.
4. Exact Hopscotch receipts settle real spend after dispatch; they do not freeze
   an upstream price beforehand. Current shared key has no confirmed task cap.
   Never activate this path on that key as a hard-dollar guarantee. A separate
   task-scoped cap/account change requires its own explicit authority and exact
   TypeSafe Jev + coding + compute totals/terms. Keep shared pool/key unchanged.
5. Native iOS session and push delivery remain untested. Local browser proof is
   not device proof; no retained phone configuration or policy was changed.

Build/activation decisions must present actual current cost/terms rather than a
model estimate. This ledger is neither owner approval nor a deployment plan.
